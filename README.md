# Construindo formulários
Sua tarefa é construir, em HTML, esse formulário de acordo com as especificações abaixo.

## 1. Dados pessoais
Crie uma seção destinada exclusivamente às informações pessoais do aluno.
Essa seção deverá solicitar:

* Nome completo;
* Data de nascimento;
* CPF;
* Sexo;
* E-mail;
* Telefone para contato.

OBS: O nome completo, a data de nascimento, o CPF e o e-mail deverão ser informações obrigatórias.
Para o campo de sexo, o usuário deverá poder escolher apenas uma opção entre:

* Feminino;
* Masculino;
* Outro;
* Prefiro não informar.

## 2. Endereço
Crie uma seção específica para as informações de endereço.
Deverão ser solicitados:

* CEP;
* Estado;
* Cidade;
* Bairro;
* Rua;
* Número;
* Complemento.

O preenchimento do complemento deverá ser opcional.
Para o estado, o usuário deverá escolher uma opção a partir de uma relação de estados brasileiros.

## 3. Informações sobre o plano

Crie uma seção destinada à escolha do plano que o aluno deseja contratar.
O usuário deverá escolher apenas uma das seguintes opções:

* Plano mensal;
* Plano trimestral;
* Plano semestral;
* Plano anual.

Também deverá ser solicitado o turno de preferência para frequentar a academia:

* Manhã;
* Tarde;
* Noite.

Além disso, o formulário deverá perguntar qual é o principal objetivo do aluno. O usuário deverá poder escolher uma das seguintes opções:

* Ganho de massa muscular;
* Emagrecimento;
* Condicionamento físico;
* Saúde e qualidade de vida;
* Outro.

## 4. Modalidades de interesse

Crie uma seção para identificar quais atividades oferecidas pela academia despertam interesse no aluno.
Nesse caso, o aluno poderá escolher .
As opções disponíveis serão:

* Musculação;
* Treinamento funcional;
* Natação;
* Pilates;
* Dança;
* Artes marciais;
* Spinning.

## 5. Informações complementares

Crie uma seção para que o aluno possa fornecer informações adicionais.
Deverá existir um espaço para que ele descreva seus objetivos, expectativas ou outras observações que considere importantes.
Também deverá ser possível informar se o aluno já praticou atividades físicas anteriormente.
Para essa informação, deverão existir as opções:
Sim; Não.

Caso o aluno responda que sim, deverá haver um espaço para que ele informe quais atividades físicas já praticou.

## 6. Documentação

Crie uma seção destinada ao envio de documentos.
O aluno deverá poder anexar um documento de identificação em formato de arquivo.
O envio desse documento deverá ser obrigatório.

## 7. Termos e autorização

Antes de finalizar o cadastro, o usuário deverá visualizar uma mensagem informando que os dados fornecidos serão utilizados pela academia para fins de cadastro e contato.
O formulário deverá conter uma opção para que o usuário declare que:
Li e concordo com os termos de uso e autorizo o tratamento dos dados fornecidos para realização do cadastro.
O cadastro não poderá ser enviado sem que essa opção seja marcada.

## 8. Botões de controle

Ao final do formulário deverão existir dois botões:
Um botão para enviar os dados preenchidos;
Um botão para limpar todos os dados preenchidos e retornar o formulário ao estado inicial.
Regras gerais: O formulário deverá atender às seguintes condições:

Todos os campos deverão possuir uma identificação clara para o usuário.
Os campos obrigatórios deverão ser identificados e possuir mecanismos de validação.
O usuário deverá receber informações que facilitem o preenchimento dos campos, quando necessário.
Os campos deverão possuir nomes que permitam identificar claramente qual informação está sendo enviada.
As informações deverão ser agrupadas de acordo com seu significado.
Cada grupo de informações deverá possuir um título descritivo.
O formulário deverá apresentar uma organização lógica, facilitando seu preenchimento.
Deverão ser utilizados recursos de validação disponíveis no próprio HTML sempre que forem adequados.
O formulário deverá funcionar corretamente mesmo sem a aplicação de CSS.
A estrutura deverá ser semanticamente organizada e seguir boas práticas de HTML.
